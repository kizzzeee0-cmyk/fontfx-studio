# FontFX Studio v1.2.4

웹폰트 또는 로컬 폰트를 불러와 **글자 하나하나를 독립 레이어처럼 편집하고**, Photoshop 스타일의 다중 획/내부 그림자를 적용한 뒤 **투명 배경 PNG**로 저장하는 로컬 웹앱입니다.

## 가장 빠른 실행 방법

1. ZIP 파일을 원하는 폴더에 압축 해제합니다.
2. `index.html`을 Chrome 또는 Edge로 엽니다.
3. 왼쪽에서 캔버스 크기를 입력하고 `캔버스 크기 적용`을 누릅니다.
4. 폰트를 선택하거나 가져옵니다.
5. 텍스트를 입력하고 `글자별 레이어 생성`을 누릅니다.
6. 가운데 미리보기에서 글자를 직접 움직입니다.
7. 오른쪽에서 획/내부 그림자/레이어 순서를 조정합니다.
8. 오른쪽 아래에서 전체 PNG 또는 글자별 ZIP을 저장합니다.

`START_FontFX_Studio.bat`을 더블클릭해도 기본 브라우저로 실행됩니다.

## v1.2.4 핵심 기능

### 1) 폰트 불러오기

- Windows 기본/시스템 폰트 선택
- Google Fonts 같은 웹 CSS URL 추가
- WOFF / WOFF2 / TTF / OTF 직접 URL 추가
- 내 컴퓨터의 TTF / OTF / WOFF / WOFF2 파일 즉시 불러오기
- 가져온 폰트를 글자별로 서로 다르게 적용

> 로컬 폰트 파일은 브라우저 메모리에서만 사용합니다. 이 앱 자체가 서버로 업로드하지 않습니다.

### 2) 완전 투명 캔버스

- 가로/세로 픽셀 직접 입력: 32~8192 px
- 1:1, 16:9, 9:16, 3:1 프리셋
- 체크무늬는 편집용 투명 표시이며 PNG에는 포함되지 않음

### 3) 글자별 독립 편집

입력한 단어를 한 덩어리 텍스트가 아니라 **한 글자 = 한 레이어**로 생성합니다.

- 캔버스에서 드래그: 위치 이동
- 모서리 네모 핸들: 크기 조절
- 위쪽 원형 핸들: 회전
- Shift + 클릭: 여러 글자 선택
- Delete / Backspace: 선택 글자 삭제
- X / Y / 각도 / 배율 값을 숫자로 직접 입력 가능
- 글자 자체, 폰트, 글자 크기, 채우기 색상 개별 변경 가능
- 레이어 위/아래/맨 위/맨 아래 이동
- 레이어 드래그 재정렬
- 표시/숨김, 잠금

### 4) 단색 / 그라데이션 채우기

글자마다 채우기 방식을 독립적으로 선택할 수 있습니다.

- 단색
- 선형 그라데이션
- 원형 그라데이션
- 그라데이션 색상 스톱을 원하는 만큼 추가
- 각 스톱의 색상과 위치(0~100%) 직접 입력
- 각도 숫자 입력
- 중심 X / Y 위치 직접 이동(-300~300%)
- 범위 1~600% 조절
- 글자 바깥에 중심을 두는 그라데이션도 가능
- 상단 빛반사 / 3단 부드럽게 / 캔디 광택 / 위 밝게·아래 진하게 프리셋
- 미리보기 바에서 현재 그라데이션 즉시 확인

`범위`를 작게 하면 색 변화가 좁은 영역에 몰리고, 크게 하면 더 넓고 완만하게 퍼집니다. `중심 X/Y`를 0~100 밖으로 입력하면 빛의 중심을 글자 바깥으로 이동시킬 수 있습니다.

### 5) 그룹

위치·각도·크기를 글자별로 조정한 뒤 여러 글자를 Shift로 선택하고 `선택 글자 그룹화`를 누릅니다.

- 그룹 생성 시 글자 스타일을 강제로 통일하지 않습니다.
- 그룹 글자는 캔버스에서 클릭하면 자동으로 함께 선택되고 같이 이동합니다.
- `그룹 합체 효과 편집`이 켜져 있으면 획/내부 그림자가 글자별이 아니라 **합쳐진 단어 실루엣 전체**에 적용됩니다.
- 언제든 그룹 해제 가능

### 6) 무제한 다중 획

`+ 획 추가` 버튼으로 획 레이어를 계속 추가할 수 있습니다. 프로그램상 고정 개수 제한을 두지 않았습니다.

각 획별 조절 항목:

- 혼합 모드
- 불투명도
- 색상
- 획 레이어 위/아래 순서
- 삭제

지원 혼합 모드:

- 차이
- 더 밝게

### 7) 무제한 다중 내부 그림자

`+ 그림자 추가`로 여러 개를 겹칠 수 있습니다.

각 내부 그림자별 조절 항목:

- 불투명도

- 크기/블러
- 윤곽선: 선형 / 부드럽게 / 단단하게 / 둥글게 / 가파르게
- 품질 1~5
- 레이어 순서

원하는 기준 색상 하나를 고르면 다음 계열을 자동 생성합니다.

또한 16개의 미리 만들어진 팔레트를 포함합니다.

### 9) PNG 저장

#### 전체 1장 저장

`전체를 PNG 1장으로 저장`

- 배경 완전 투명
- 지정한 캔버스 크기 유지
- PNG 무손실 저장
- 1× / 2× / 4× 출력

#### 글자별 저장

`글자별 PNG를 ZIP 폴더로 저장`

ZIP 안에 다음처럼 자동 정리됩니다.

```text
fontfx-design_characters/
  01_유.png
  02_남.png
  03_라.png
```

두 가지 저장 방식:

- `글자 영역만 딱 맞게`: 투명 여백을 최소화한 개별 PNG
- `원본 캔버스 위치 유지`: 모든 파일을 원본 캔버스 크기로 저장하고 해당 글자 위치를 유지

### 10) 프로젝트 저장

- `프로젝트 저장`: `.fontfx.json`
- `프로젝트 불러오기`: 다시 편집 가능
- Ctrl+Z / Ctrl+Y 또는 상단 버튼으로 실행취소/다시실행
- 최대 80단계 편집 기록

> 로컬 업로드 폰트 자체의 파일 바이트는 프로젝트 JSON 안에 넣지 않습니다. 프로젝트를 다시 열 때 동일 로컬 폰트를 다시 한 번 불러오면 됩니다. 웹 CSS/URL 폰트 정보는 프로젝트에 보존됩니다.

## 웹폰트 추가 방법

### A. Google Fonts / 웹 CSS 방식

1. 폰트 제공 사이트에서 CSS 주소를 복사합니다.
2. `Google Fonts / 웹 CSS`를 펼칩니다.
3. `CSS 주소`에 붙여넣습니다.
4. CSS에 적힌 정확한 `font-family` 이름을 입력합니다.
5. `웹 CSS 폰트 추가`를 누릅니다.

예시 형식:

```text
CSS 주소: https://fonts.googleapis.com/css2?family=Noto+Sans+KR:wght@700&display=swap
font-family 이름: Noto Sans KR
```

### B. 폰트 파일 URL 방식

1. 브라우저에서 직접 접근 가능한 `.woff2`, `.woff`, `.ttf`, `.otf` 주소를 준비합니다.
2. 원하는 표시 이름과 URL을 입력합니다.
3. `URL 폰트 추가`를 누릅니다.

원격 서버가 CORS를 차단하면 브라우저 보안 정책 때문에 불러오거나 PNG로 저장할 수 없습니다. 그때는 같은 폰트 파일을 내려받아 `내 컴퓨터 폰트 파일` 방식으로 넣는 것이 가장 확실합니다.

### C. 로컬 파일 방식 — 가장 안정적

1. `내 컴퓨터 폰트 파일`을 펼칩니다.
2. TTF/OTF/WOFF/WOFF2 파일을 선택합니다.
3. 파일명이 폰트 이름으로 등록됩니다.
4. 폰트 목록에서 바로 선택합니다.

## 고화질 출력 원칙

FontFX Studio는 최종 출력 때 화면 캡처를 저장하지 않습니다. 지정한 논리 캔버스 크기로 **새 출력 캔버스를 다시 렌더링**하고 PNG로 저장합니다.

- PNG 자체는 손실 압축을 사용하지 않습니다.
- 1×: 입력한 캔버스 픽셀을 그대로 출력
- 2×: 가로/세로 각각 2배
- 4×: 가로/세로 각각 4배
- 효과 렌더링용 글자 표면은 별도의 고배율 버퍼에서 생성하여 확대 시 계단 현상을 줄입니다.

단, 매우 작은 원본 폰트를 수십 배 이상 확대하거나 운영체제/브라우저 자체 폰트 렌더러가 다른 경우 미세한 차이는 생길 수 있습니다.

## 자주 생기는 문제

### 폰트가 기본 글꼴로 보임

- `font-family` 이름의 띄어쓰기까지 정확히 입력했는지 확인합니다.
- 웹 CSS가 아니라 폰트 파일 주소라면 `직접 WOFF/TTF URL`을 사용합니다.
- 가장 확실한 해결은 폰트 파일을 로컬 업로드하는 것입니다.

### 원격 폰트 URL이 안 불러와짐

원격 서버가 다른 사이트에서의 폰트 사용을 막는 CORS 설정일 수 있습니다. 로컬 파일 업로드를 사용하세요.

### 글자가 너무 크게 생성됨

왼쪽 `기본 크기`를 낮추고 다시 생성하거나, 기존 글자를 선택해 오른쪽 `크기(px)`/`배율`을 줄입니다.

### 효과 편집이 그룹 전체에 적용됨

`그룹 효과 동시 편집`을 끄면 현재 활성 글자 하나만 바뀝니다.

### 개별 PNG에서 원래 위치가 필요함

`글자별 저장 방식`을 `원본 캔버스 위치 유지`로 바꿉니다.

## v1.2.2 웹폰트 입력법

웹 CSS 입력칸에는 아래 형식을 모두 사용할 수 있습니다.

### Google Fonts CSS URL

```text
https://fonts.googleapis.com/css2?family=Noto+Sans+KR:wght@400;700&display=swap
```

### Google Fonts에서 복사한 link 코드 전체

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Noto+Sans+KR:wght@400;700&display=swap" rel="stylesheet">
```

FontFX가 preconnect 주소를 폰트 CSS로 잘못 인식하지 않고 `rel="stylesheet"` 링크를 자동 선택합니다.

### @import

```css
@import url('https://fonts.googleapis.com/css2?family=Noto+Sans+KR:wght@400;700&display=swap');
```

### @font-face 코드

```css
@font-face {
  font-family: 'MyFont';
  src: url('https://example.com/MyFont.woff2') format('woff2');
}
```

`font-family 이름` 입력칸은 이제 선택 사항입니다. 자동 감지가 되지 않을 때만 정확한 이름을 직접 적어주세요.

### 계속 기본 폰트처럼 보이는 경우

1. 화면의 `가져온 폰트 관리`에서 미리보기 모양을 확인합니다.
2. CSS 연결은 성공했지만 미리보기가 기본 글꼴이면 CSS 안의 정확한 `font-family` 이름을 직접 입력합니다.
3. 직접 `.woff/.woff2/.ttf/.otf` URL을 사용할 때는 해당 파일 서버가 CORS를 허용해야 합니다.
4. CORS가 막힌 폰트라면 파일을 내려받아 `내 컴퓨터 폰트 파일`로 넣는 것이 가장 확실합니다.

### 획 / 내부 그림자 프리셋 저장

오른쪽의 `다중 획`과 `내부 그림자` 영역에서 현재 설정을 이름을 붙여 저장할 수 있습니다.

- **현재 획 저장**: 현재 범위의 획 전체를 저장
- **현재 그림자 저장**: 내부 그림자 전체를 저장
- 드롭다운에서 프리셋을 선택하고 `적용`을 누르면 현재 글자/그룹의 해당 효과 스택을 교체
